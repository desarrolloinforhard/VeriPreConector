Version 1.16.13
- El envio de publicidades ahora adapta la lista al dispositivo real seleccionado.
- Si el dispositivo soporta multi-monitor y no hay pantallas configuradas por grupo, duplica el grupo activo en todas las pantallas detectadas.
- Si el dispositivo es de una sola pantalla y existen grupos con display configurado, envia solo el grupo activo para evitar mezclas.
- La confirmacion previa de envio ahora aclara esta regla de fallback por dispositivo.

Version 1.16.12
- Antes de enviar publicidades ahora se muestra un resumen por pantalla y grupo para confirmar la transmision.

Version 1.16.11
- El envio de publicidades vuelve a mandar todos los grupos que tengan pantalla asignada en una sola corrida.
- Si no hay grupos con pantalla configurada, se mantiene el comportamiento de enviar solo el grupo activo.

Version 1.16.7
- Agregada asignacion de pantalla por grupo de publicidades.
- El envio de publicidades ahora puede incluir `display_index` y `grupo` para players multi-monitor.
- Si el dispositivo no soporta `/api/veri/configuracion_player`, el envio mantiene compatibilidad legacy de una sola pantalla.
- Si el player informa una sola pantalla, se omite `display_index` para evitar romper verificadores, totems o APKs anteriores.
